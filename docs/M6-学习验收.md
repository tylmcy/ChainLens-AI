# M6 学习验收

完成代码与测试只说明功能可运行。以下四项需要你自己操作并口头解释，才能把 M6 视为已掌握。

1. **解释流式请求**：指出 `web/src/api.ts` 为什么用 `fetch` 发 POST、`web/src/sse.ts` 如何拼接跨网络块的 UTF-8、CRLF 和多行 `data`。说明 `EventSource` 不能直接发送这个 POST 请求。
2. **独立修改展示**：在 `web/src/render.ts` 给 finding 卡片增加一个你选定的证据字段，保持动态文本使用 `textContent`。运行 `pnpm typecheck && pnpm test`，再在浏览器中找到该字段。
3. **复现测试**：独立运行 `cd web && pnpm test`，挑选一条 SSE 分块测试，修改输入片段让它失败，再恢复并说明失败原因。
4. **排查一次失败**：断开本地 Anvil 或输入不存在的交易哈希，观察页面错误；用浏览器网络面板确认 HTTP/SSE 响应，再定位前端状态更新与后端错误码。恢复环境后重试成功。

自查时记录你改动的文件、执行的命令、观察到的结果和仍不理解的问题。`M6 代码完成` 与 `本人已掌握 M6` 是两种不同状态。
